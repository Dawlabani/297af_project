# Transcriptomic Profiling of Breast Cancer Subtypes

This project analyzes TCGA-BRCA RNA-seq data to compare major breast cancer molecular subtypes against normal tissue. The repo now separates the workflow into dedicated notebooks for Phases 1 through 4, while the original combined notebook is kept as a reference. Current work covers Phase 1 QC / exploratory analysis, Phase 2 differential expression analysis, the GO Biological Process portion of Phase 3 enrichment, and a scaffolded Phase 4 network-analysis workflow. A stricter cleanup pass for the partner handoff matrix is also included for downstream DEA reruns.

## What has been done so far

### 1. Preprocessing and filtering
- A pre-filtered TCGA-BRCA expression matrix was used as the starting point for this notebook.
- The dataset was already cleaned before this analysis notebook begins, including sample selection / subtype labeling needed for the five groups used here:
  - Basal: 181 samples
  - Her2: 77 samples
  - LumA: 528 samples
  - LumB: 198 samples
  - Normal: 134 samples
- The main analysis starts from `exp_data_filtered.pkl`, which represents the pre-filtered expression data handed off for downstream QC and DEA.

### 2. Phase 1: QC and exploratory analysis
- Loaded the pre-filtered TCGA-BRCA expression matrix.
- Performed gene-name deduplication by keeping the duplicate entry with the highest mean expression.
- Reduced the matrix from 60,660 rows to 59,427 unique genes across 1,118 samples.
- Generated exploratory plots for:
  - library size distributions by subtype
  - PCA subtype clustering
  - sample-sample correlation heatmap

### 3. Phase 2: differential expression analysis
- Ran PyDESeq2 subtype-vs-normal comparisons for:
  - Basal vs Normal
  - Her2 vs Normal
  - LumA vs Normal
  - LumB vs Normal
- Used significance thresholds:
  - `|log2FC| > 1.5`
  - `adjusted p-value < 0.01`
- Generated:
  - volcano plots for all four comparisons
  - DEG summary counts
  - heatmap of top DEGs across subtypes
  - subtype-specific vs shared DEG count summary

## Current results summary

- Basal vs Normal: 6,603 significant DEGs
- Her2 vs Normal: 6,372 significant DEGs
- LumA vs Normal: 4,544 significant DEGs
- LumB vs Normal: 6,737 significant DEGs
- Union of top subtype DEGs used in the heatmap: 84 genes
- Total unique significant DEGs across all four subtype comparisons: 11,786
- Shared across all four subtypes: 1,611 genes

## Files in this folder

### Main notebooks
- `phase1_preprocessing_qc.ipynb`: data retrieval, filtering, subtype labeling, and QC / exploratory analysis for Phase 1
- `phase2_differential_expression.ipynb`: subtype-vs-normal PyDESeq2 analysis and DEG visualization for Phase 2
- `phase3_functional_enrichment.ipynb`: standalone Phase 3 notebook for GO Biological Process enrichment and subtype dot plots; KEGG is deferred for now
- `phase4_network_analysis.ipynb`: Phase 4 STRING / NetworkX workflow for subtype-specific PPI network analysis
- `old/phase1_qc.ipynb`: original combined notebook kept as a legacy reference; it includes the earlier combined Phase 1, Phase 2, and Phase 3 GO BP workflow

### Intermediate inputs
- `exp_data_filtered.pkl`: filtered expression matrix generated by `phase1_preprocessing_qc.ipynb`
- `exp_data_filtered_strict.pkl`: stricter DEA-ready matrix generated by `scripts/audit_and_clean_expression_matrix.py` or by the strict cleanup step in `phase1_preprocessing_qc.ipynb`
- `metadata.pkl`: subtype annotation table generated by `phase1_preprocessing_qc.ipynb`
- `metadata_strict.pkl`: stricter metadata table written when `metadata.pkl` is available during strict cleanup

The Phase 2 notebook now prefers the strict files when they exist. In the current repo snapshot, `metadata.pkl` is missing, so the strict metadata file cannot be regenerated until the Phase 1 metadata handoff is recreated.
